# 文化庁「国指定文化財等データベース」スナップショットの取り方（人手）

## 利用条件（2026-09-08 実測）

<https://kunishitei.bunka.go.jp/top/policy> より:

- **文字情報**: 出典を記載の上、自由に利用できる
- **画像**: 第三者が権利を有するものがあるため、作品ごとに個別の許諾が必要

本アプリは **文字情報のみ**を使い、画像は一切転載しない（SPEC §3.4 / §10）。

## なぜ自動取得しないか

構想書 §2.1 のとおり、CSV の全件出力に障害があり 2,000 件以下に分割して出力する
運用が案内されている。検索条件つきの動的画面を機械で巡回する経路は採らない。

## 手順

1. <https://kunishitei.bunka.go.jp/bsys/index> を開く
2. 文化財分類「史跡名勝天然記念物」を選ぶ
3. キーワードに「古墳」を指定する
4. 1 ファイルが 2,000 件以下になるよう都道府県などで分割する
5. CSV を出力する
6. `data/raw/bunka/YYYY-MM-DD/` に保存する
7. `python scripts/import_bunka_csv.py`（L1 で用意する）を実行する

## 列名の対応

CSV の列名が変わっても取り込みが壊れないよう、対応は設定ファイル
`config/bunka_columns.yml`（L1 で用意する）に外出しする。
未知の列は捨てずに `raw_extra` へ退避する。
